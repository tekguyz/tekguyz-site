The brand end card as a 4:5 post, light and dark, built from the mark, the wordmark, the tagline and the address.

This is a specimen of the composition. The shipped pictures and clips are written by the media build tool in `tekguyz-one/brand/media/build`. Never hand-edit those files.

## Rules

- Mark, then wordmark, then the tagline, then `tekguyz.com`. Centred. Nothing else.
- Post one theme, not both on the same day. Light is the default.
