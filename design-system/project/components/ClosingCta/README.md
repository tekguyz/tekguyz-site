## What the consumer provides

Optional `headline`, `sub`, `trust` (three short facts), `cta` and `link`. The defaults are the live site's words.

## Rules

- This is the one centred section on the site.
- A band, not a box: full bleed, no radius, no border. The stripe above it is its lid and the dark footer below is its floor.
- Inside: headline, 24px, subhead, 48px, trust row, 24px, one `large` button, 16px, one quiet text link.
- Below 767px the trust row stacks and its dots disappear.
