Someone else's words, on an ink card, with a source a reader can check.

## What the consumer provides

The quote as children, `author` and `source`.

## Rules

- Real quotation marks, because these are not our words. Attribution is a first name plus where it can be checked, such as "Joe M. · Verified Google review".
- **There is no numeric rating. Never add stars or a score.**
- The card carries `.ink-band`, so it is dark in both themes. Never put a hex inside it.
