The dot, label and sentence that report the result of a lead-capture attempt.

## What the consumer provides

`tone` (`success` or `error`), a short `label`, and the sentence as children.

## Rules

- The colour is a 6px dot only. The label is `tg-fg`, so remove the colour and the sentence still reads.
- Say what happened in plain English and what to do next. An error names the public address, hello@tekguyz.com.
