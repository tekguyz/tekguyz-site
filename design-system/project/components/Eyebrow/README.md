The small uppercase label above a section head. It is the only uppercase text in the system.

## What the consumer provides

The words, in sentence case: the component sets the case. Pass `solution` to colour it in that line's accent, which uses the `-on-bg` token so it passes contrast in both themes.

## Rules

- `eyebrow` style: 12px, weight 700, tracking 0.1em. Colour is `tg-secondary` unless it names a Solution.
- One per section, above the head, never inside a sentence.
