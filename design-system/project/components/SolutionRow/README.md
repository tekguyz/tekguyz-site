A full-width hairline row: dot, Solution name, one-line hook, arrow.

## What the consumer provides

`solution`, and optionally `name`, `hook`, `href`, and `last` for the closing hairline. The four Solutions' names and hooks are built in.

## Rules

- No card, no fill, no icon. Four identical cards is a named anti-pattern and this row replaces it.
- Hover darkens the hairline to `tg-border-strong`, shifts the title and arrow 4px right and draws the `tg-rule` bar. Nothing lifts.
- The title is `subhead`, one step below the section head's `display`. Keep the four hooks about the same length.
