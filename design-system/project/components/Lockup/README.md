The master lockup: the mark plus the TEKGUYZ wordmark as outlined paths, so it needs no font.

## What the consumer provides

`height` in px (default 32) and `stroke` for the connectors. The wordmark takes `tg-fg`, so it flips with the theme.

## Rules

- **The wordmark is Geist 800, tracking -0.025em, in capitals, as outlines.** Never retype it in another font.
- Clear space on every side is one node diameter.
- On a surface that is dark in both themes, put the lockup inside `.ink-band` or `.footer-dark` and it reads correctly.
- For a file that cannot run this component (email, slides, a social profile), use `assets/Logos/lockup-universal-ink.svg` or `lockup-universal-white.svg`.
