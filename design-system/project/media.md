# Media: marks, covers and clips

Every file here is made by the media build tool from fixed numbers. Pick the right file; do not resize, crop, recolour or edit one.

## Which mark, on which ground

| Ground | Icon | Lockup |
| --- | --- | --- |
| Any ground, one file | `icon-universal.svg` | `lockup-universal-ink.svg` on light, `lockup-universal-white.svg` on dark |
| Light surface, full detail | `icon-universal.svg` | `lockup-master.svg` |
| One colour, black | `icon-mono-black.svg` | `lockup-mono-black.svg` |
| One colour, white | `icon-mono-white.svg` | `lockup-mono-white.svg` |
| Browser tab | `favicon.svg`, on a `#101010` plate | not used |

- The universal icon's connectors are `#7B8291` so they read on light and dark. The master lockup's are the light hairline `#E5E7EB`.
- The wordmark in every lockup is outlined Geist 800. No font is needed.
- Clear space is one node diameter on every side.
- **Never draw the mark, never recolour a circle, never add a container, a shadow or an outline.** One-colour versions are for print, embossing and stamps; everywhere else use the colours.

## Brand video and loops

15 seconds, no sound, H.264. It shows the logo, the four services and the end card "TEKGUYZ. We build tech that actually works. tekguyz.com". Every file has a dark twin.

| File | Size | Use |
| --- | --- | --- |
| `tekguyz-brand-feed-4x5.mp4` | 1080 x 1350 | Facebook feed |
| `tekguyz-brand-stories-9x16.mp4` | 1080 x 1920 | Reel and Story |
| `tekguyz-brand-square-1x1.mp4` | 1080 x 1080 | LinkedIn |
| `tekguyz-logo-loop.gif` | 480 x 480, 3 s | Email, decks, anywhere a GIF works |

Post light or dark, not both on the same day. Light is the default; dark has more edge in a light feed. Always put tekguyz.com in the caption too, because a Reel's caption can cover the end card's address.

## Captions

- Instagram and Facebook: "A real person who replies. Real AI that fixes real problems." then the four Solution names, then "We build tech that actually works.", then tekguyz.com.
- Google Business Profile: no hashtags, one short line, tekguyz.com.
- Posts are proof of work from live builds. Voice is "we", the founder with AI agents. Never imply staff and never call it a studio.
