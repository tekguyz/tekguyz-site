# Social

Profile pictures, covers and the link share image, at the exact sizes the platforms take. Written by the media build tool.

| File | Size | Use |
| --- | --- | --- |
| `avatar-light-1080.png` | 1080 | Profile picture on a light platform |
| `avatar-dark-1080.png` | 1080 | Profile picture on a dark platform |
| `linkedin-cover-2256x382.png` | 2256 x 382 | LinkedIn company cover |
| `facebook-cover-1702x630.png` | 1702 x 630 | Facebook page cover |
| `gbp-cover-2048x1152.png` | 2048 x 1152 | Google Business Profile cover |
| `og-image-1200x630.png` | 1200 x 630 | Link share image |

## Rules

- Do not resize, crop or edit a file. If a size is wrong, change the build tool and rebuild.
- The four-colour signature stripe is allowed on the covers and the share image. It does not go on avatars.
- A picture is never a drawn mockup of a build. Screenshots belong to the website's own repository.
