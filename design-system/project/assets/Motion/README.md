# Motion

Two logo loops and the brand video in its feed size, each in a light and a dark version. 15-second video, no sound, H.264; loops are 480 x 480 and 3 seconds.

| File | Use |
| --- | --- |
| `tekguyz-logo-loop.gif` | Email, decks, anywhere a GIF works, on a light ground |
| `tekguyz-logo-loop-dark.gif` | The same on a dark ground |
| `tekguyz-brand-feed-4x5.mp4` | Facebook feed, 1080 x 1350, light |
| `tekguyz-brand-dark-feed-4x5.mp4` | Facebook feed, 1080 x 1350, dark |

## Rules

- Post one theme, not both on the same day. Light is the default.
- Do not resize, crop or edit a clip.
- All words in the video come from the playbook: the logo, the four Solutions, and the end card "TEKGUYZ. We build tech that actually works. tekguyz.com". No numbers, no client names, no prices.
- The 9:16 and 1:1 versions are in the repository's media folder.
